# 🍷 Mobile Project - 주류 바코드 인식 및 테이스팅 노트 공유 앱

## 📌 프로젝트 소개
이 프로젝트는 주류 바코드를 카메라로 인식하여 해당 주류의 맛과 리뷰를 확인할 수 있는 모바일 애플리케이션입니다.  
사용자는 직접 **테이스팅 노트**를 작성하고, 다른 사람들이 남긴 리뷰도 확인할 수 있습니다.  

## 🎯 주요 기능
- 📸 **바코드 인식**: 카메라로 주류 바코드를 스캔하여 해당 상품 정보를 조회
- 🔍 **주류 검색**: 주류 이름으로 상품을 검색하고 상세 정보 확인
- ⭐ **리뷰 및 별점**: 주류별 평균 별점 확인, 별점 리뷰 작성, 다른 사용자 리뷰 조회
- ✍ **테이스팅 노트 작성**: 시음 날짜, 향, 맛, 평가 등을 기록하는 개인 테이스팅 노트 작성
- 🗂 **노트 관리 및 공유**: 내 테이스팅 노트를 조회하고 공개 여부에 따라 다른 사용자와 공유
- 👤 **사용자 정보 관리**: 로그인, 회원가입, 프로필 이미지 설정, 마이페이지 확인

## 📱 주요 화면
- **Login / Signup**: 로그인 및 회원가입 화면
- **Home**: 주류 목록, 카테고리 필터, 이름순/별점순/리뷰순 정렬 화면
- **Search**: 주류 이름 검색 화면
- **BarcodeScanMenu**: 카메라 권한 요청 및 바코드 스캔 화면
- **Detail / BarcodeDetail**: 주류 상세 정보, 평균 별점, 리뷰 작성 및 조회 화면
- **TasteNote**: 내가 작성한 테이스팅 노트 목록 화면
- **WriteDownNote**: 테이스팅 노트 작성 화면
- **ViewTasteNote**: 테이스팅 노트 상세 조회 화면
- **MyPage / UserInfo**: 내 정보 및 다른 사용자 공개 노트 조회 화면

## 📁 디렉토리 구조
```text
.
├── App.js                         # 앱 진입점
├── AppContext.js                  # 전역 사용자 상태와 API URL 관리
├── app.json                       # Expo 앱 설정
├── assets/                        # 앱 아이콘, 스플래시 이미지
├── components/                    # 공통 스타일/입력 관련 컴포넌트
├── images/                        # 메뉴, 프로필, 주류, 바코드 이미지 리소스
├── json/                          # 향/맛 관련 정적 JSON 데이터
├── navigation/
│   ├── StackContainer.js          # 스택 네비게이션 설정
│   ├── TabContainer.js            # 하단 탭 네비게이션 설정
│   ├── components/                # 네비게이션 내부 공통 컴포넌트
│   ├── menus/                     # 하단 탭 메뉴 화면
│   ├── screens/                   # 주요 앱 화면
│   └── test/                      # 테스트/실험용 화면 코드
├── package.json                   # 의존성 및 실행 스크립트
└── package-lock.json              # npm 의존성 잠금 파일
```

## 🛠 실행 환경
- **Node.js / npm** 기반 프로젝트
- **Expo SDK 53**
- **React 19**
- **React Native 0.79**

백엔드 API 기본 주소는 `AppContext.js`의 `apiUrl`에서 관리합니다.
